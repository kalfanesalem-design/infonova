# InfoNova

Site éditorial statique en français.

## Mise en ligne

1. Ouvrir **Settings → Pages** dans GitHub.
2. Dans **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner `feature/infonova-starter` et le dossier `/ (root)`.
4. Enregistrer.

Les espaces publicitaires sont réservés mais aucun compte publicitaire n’est encore configuré.
